# UTS - Collaborative Academic Information System (CAIS)

## 1. Deskripsi Aplikasi

Collaborative Academic Information System (CAIS) merupakan prototype aplikasi informasi akademik sederhana yang dikembangkan secara kolaboratif untuk memenuhi Ujian Tengah Semester Praktikum Collaborative Computing.

Aplikasi ini menyediakan halaman beranda, login, dashboard akademik, dan modul data mahasiswa.

2. Buka folder proyek menggunakan Visual Studio Code.
3. Pastikan seluruh file proyek tersedia.
4. Jalankan file index.html menggunakan browser atau ekstensi Live Server.
